# Arun & Dhiya | Wedding Days Countdown PWA 💍✨

A clean, minimal, premium Progressive Web App (PWA) that calculates and displays the remaining days until **Arun & Dhiya's Wedding** on **November 20, 2026**.

---

## 🚀 Features

- **Primary Focus**: Large, prominent Days Remaining counter.
- **Accurate Date Handling**: Local midnight calendar calculation (Indian standard time / local timezone handling).
- **Dynamic States**:
  - **Countdown**: Displays exact remaining days (e.g. `88 Days To Go`).
  - **Wedding Day**: Displays `It's Our Wedding Day! ❤️💍`.
  - **Post-Wedding**: Displays `We Are Married ❤️`.
- **Progressive Web App (PWA)**:
  - Fully installable on Chrome, Android, iOS Safari, and Edge.
  - Opens in standalone mobile app window.
  - Offline caching via Service Worker.
- **Minimal & Lightweight**: Zero external frameworks, super fast load times, and responsive mobile-first glassmorphism design.

## 🌐 How to Deploy to GitHub Pages (Step-by-Step)

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com/new) and create a new repository (e.g., `arun-dhiya-wedding`).

2. **Upload Files**:
   - Push or upload all files (`index.html`, `style.css`, `script.js`, `manifest.json`, `service-worker.js`, `README.md`, and the `icons/` folder) to your repository's `main` branch.

3. **Enable GitHub Pages**:
   - Go to your repository **Settings**.
   - Scroll down to **Pages** in the left sidebar.
   - Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
   - Select **Branch**: `main` and **Folder**: `/ (root)`.
   - Click **Save**.

4. **Your Live PWA URL**:
   - Within 1–2 minutes, your website will be live at:
     `https://<your-github-username>.github.io/arun-dhiya-wedding/`

## 📱 How to Install as a Mobile App (PWA)

### Android / Chrome:
1. Open the live GitHub Pages URL in Chrome on your phone.
2. Tap the 3 dots menu or look for the banner **"Add Arun & Dhiya to Home Screen"** or **"Install App"**.
3. Tap **Install**.

### iOS / Safari (iPhone):
1. Open the URL in **Safari**.
2. Tap the **Share** button (bottom middle icon).
3. Scroll down and tap **"Add to Home Screen"**.
